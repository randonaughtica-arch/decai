# AI Deco

Select a group of objects in the editor, press the **star button** on the right-hand edit bar, and describe the decoration you want. Claude places new objects around your selection.

- The AI may only use **object IDs that appear in your selection**, plus any you add under *Extra Object IDs* in the mod settings. Select a few deco pieces you like along with the area to decorate.
- Generated objects are selected afterwards and can be undone in one step.
- Requires your own Anthropic API key (set it in the mod settings).
